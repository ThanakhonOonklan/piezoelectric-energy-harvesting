# CJMCU LTC3588-1 Nanopower Piezo Harvester & Buck Module

เอกสารสเปก Pinout การตั้งค่าแรงดัน และการต่อใช้งานจริงของบอร์ด **CJMCU LTC3588-1 (Red PCB)**

---

## 1. ภาพรวมและฟังก์ชันของบอร์ด (Board Architecture)

![CJMCU LTC3588-1 Module](/d:/Github-project/piezoelectric-energy-harvesting/image/LTC3588%20Energy%20Harvester%20Module/image.png)

บอร์ด **CJMCU LTC3588-1** รวมวงจร **Low-Loss Full-Wave Bridge Rectifier** และ **High Efficiency Synchronous Step-Down (Buck) DC/DC Converter** ออกแบบมาเฉพาะสำหรับการเก็บเกี่ยวพลังงานจากแหล่งจ่าย Impedance สูง เช่น Piezoelectric Disc หรือ Solar Cell ขนาดเล็ก

```text
Piezoelectric Elements
        ↓
    [PZ1, PZ2]
        ↓
Internal Bridge Rectifier (Internal 20V Shunt Clamp)
        ↓
    VIN (Storage Capacitor)
        ↓
Synchronous Buck Converter (Nanopower UVLO)
        ↓
  VCC (Regulated VOUT, Max 100mA)
```

## 2. ตารางข้อมูลจำเพาะทางเทคนิค (Technical Specifications)

| พารามิเตอร์ | ค่าสเปก | รายละเอียด / ข้อกำหนด |
|---|---|---|
| **ชิปหลัก (IC)** | **LTC3588-1** | Linear Technology / Analog Devices |
| **ขนาดบอร์ด (Dimensions)** | **20 mm × 12.8 mm** | Red PCB, ระยะขา 2.54 mm (Standard Header) |
| **ช่วงแรงดันไฟเข้ากระแสตรง (VIN DC Input)** | **2.7V – 20.0V** | ต่อเข้าขา `VIN` ได้โดยตรง |
| **ช่วงแรงดันไฟเข้า Piezo (AC Input)** | **สูงสุด 20V** | ภายในชิปมีวงจร 20V Protective Shunt Clamp |

## 3. ขา Pinout และจุดเชื่อมต่อ (Pin Definitions)

![LTC3588 Pinout Table](/d:/Github-project/piezoelectric-energy-harvesting/image/LTC3588%20Energy%20Harvester%20Module/image%20copy%202.png)

### แถว Pin Header ฝั่งขาเข้า (Input Header):
| ขา (Pin) | คำอธิบายการต่อใช้งาน |
|---|---|
| **GND** | กราวด์ร่วมของระบบ (Ground) |
| **GND** | กราวด์ร่วมของระบบ (Ground) |
| **PZ1** | ขั้วที่ 1 ของ Piezoelectric Element (AC Input) |
| **PZ2** | ขั้วที่ 2 ของ Piezoelectric Element (AC Input) |
| **VIN** | แรงดันหลัง Rectify / หรือต่อไฟ DC เข้าตรง (2.7V–20V) สามารถต่อ Capacitor ภายนอกเพิ่มได้ |

### แถว Pin Header ฝั่งขาออก (Output Header):
| ขา (Pin) | คำอธิบายการต่อใช้งาน |
|---|---|
| **VCC** | **แรงดันไฟออกหลัก ($V_{OUT}$)** ผ่านวงจร Buck Converter (สูงสุด 100mA) |
| **EN** | **Power Good ($P_{GOOD}$)**: ให้ Logic HIGH เมื่อแรงดัน $V_{OUT} > 92\%$ ของค่าเป้าหมาย |
| **D1** | Logic Bit 1 สำหรับเลือกแรงดัน $V_{OUT}$ (ต่อ High/Low) |
| **D0** | Logic Bit 0 สำหรับเลือกแรงดัน $V_{OUT}$ (ต่อ High/Low) |
| **GND** | กราวด์ร่วม (Ground) |

## 4. ตารางการเลือกแรงดันขาออก (Output Voltage Selection)

สามารถกำหนดแรงดัน $V_{OUT}$ ได้ทั้งการต่อสายเข้าขา `D0`, `D1` หรือการแต้มตะกั่วบน **Jumper Solder Pads (D0, D1)** บนตัวบอร์ด:

| D1 | D0 | แรงดันขาออก ($V_{OUT}$) | $V_{IN}$ UVLO Rising | $V_{IN}$ UVLO Falling | การนำไปใช้งาน |
|:---:|:---:|:---:|:---:|:---:|---|
| **0 (GND)** | **0 (GND)** | **1.8V** | 4.0V | 2.8V | เซนเซอร์ประหยัดพลังงานพิเศษ |
| **0 (GND)** | **1 (HIGH)**| **2.5V** | 4.0V | 2.8V | ไมโครคอนโทรลเลอร์ 2.5V |
| **1 (HIGH)**| **0 (GND)** | **3.3V** | 5.0V | 3.6V | **ระบบ 3.3V ทั่วไป (เช่น ESP32 / Low Power MCU)** |
| **1 (HIGH)**| **1 (HIGH)**| **3.6V** | 5.0V | 3.6V | ชาร์จ Supercapacitor / 3.6V Storage |
