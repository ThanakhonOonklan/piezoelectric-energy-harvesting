# TP4056 USB-C Li-ion Charger Module

เอกสารสเปก Pinout และข้อแนะนำการใช้งานโมดูลชาร์จแบตเตอรี่ **TP4056 USB-C (พร้อมวงจร Protection)**

---

## 1. ภาพรวมโมดูล (Overview)

TP4056 เป็นชิปควบคุมการชาร์จแบตเตอรี่ Lithium-ion / Lithium Polymer แบบ Single Cell (1S - 3.7V Nominal / 4.2V Cut-off) ด้วยวิธีการชาร์จแบบ **Constant Current / Constant Voltage (CC/CV)**

```text
5V Input (USB-C / Pad)
        ↓
    [TP4056 IC] ── CC/CV Algorithm (Max 1A Default)
        ↓
[DW01A + 8205A] ── Battery Protection (Over-charge / Over-discharge)
        ↓
[B+, B-] ──> 18650 Battery
[OUT+, OUT-] ──> System Load
```

---

## 2. Pinout & จุดต่อใช้งาน

| Pad / Pin | คำอธิบายการต่อใช้งาน |
|---|---|
| **USB-C** | ช่องเสียบไฟเข้า 5V จาก Adapter หรือ Power Supply ภายนอก |
| **IN+ / IN-** | จุดบัดกรีรับไฟเข้า 5V ขนานกับพอร์ต USB-C |
| **B+** | ต่อเข้าขั้วบวก (+) ของแบตเตอรี่ 18650 (หรือ 1S2P Holder) |
| **B-** | ต่อเข้าขั้วลบ (-) ของแบตเตอรี่ 18650 |
| **OUT+** | แรงดันไฟบวกไปยังโหลด (ผ่านวงจร Protection) |
| **OUT-** | กราวด์โหลด (ผ่านชิป Protection 8205A MOSFET) |

---

## 3. ไฟแสดงสถานะ (LED Indicators)

- 🔴 **LED สีแดง (CHRG)**: กำลังชาร์จแบตเตอรี่ (Charging in progress)
- 🔵/🟢 **LED สีน้ำเงิน/เขียว (STDBY/FULL)**: แบตเตอรี่ชาร์จเต็มแล้ว (Charge complete / Standby)

---

## 4. กฎความปลอดภัยและบทบาทในโปรเจกต์ (Project Role & Constraints)

> [!IMPORTANT]
> - **TP4056 ใช้เป็น Control Experiment (Stage 4)** สำหรับทดสอบและชาร์จแบตเตอรี่ 18650 แยกต่างหากจากไฟ 5V USB ภายนอก
> - **ห้ามนำ Piezo ต่อเข้า TP4056 โดยตรง**: TP4056 ต้องการแรงดันคงที่ 4.5V - 5.5V ที่มีกระแสต่อเนื่องเพียงพอ ไม่สามารถทำงานร่วมกับ Pulse พลังงานต่ำของ Piezo ได้
> - **ห้ามต่อขนานร่วมกับ PowerBank Module**: ไม่ควรต่อจุดชาร์จของ TP4056 ขนานกับสายชาร์จของโมดูลอื่นเข้าแบตเตอรี่พร้อมกันโดยไม่มี Power-Path Management
