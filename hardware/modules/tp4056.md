# TP4056 USB-C Li-ion Charger Module (with Dual Protection)

เอกสารสเปก Pinout และข้อแนะนำการใช้งานโมดูลชาร์จแบตเตอรี่ **TP4056 (TC4056A) Type-C** พร้อมระบบป้องกันคู่ (Dual Protection DW01A + 8205A)

---

## 1. ภาพรวมและส่วนประกอบบนบอร์ด (Board Architecture)

![TP4056 Module Layout](/d:/Github-project/piezoelectric-energy-harvesting/image/tp4056_charger/tp4056_module_wiring_pinout.png)

![TP4056 PCB Top View](/d:/Github-project/piezoelectric-energy-harvesting/image/tp4056_charger/tp4056_module_board_layout.png)

โมดูลนี้ประกอบด้วยชิปหลัก 3 ตัว:
1. **TC4056A (U1):** ชิปควบคุมการชาร์จแบตเตอรี่ Lithium-ion แบบ Linear Constant-Current / Constant-Voltage (CC/CV)
2. **DW01A (U2):** ชิปตรวจจับความปลอดภัยของแบตเตอรี่ (Over-charge, Over-discharge, Short-circuit protection)
3. **8205A (U3):** Dual N-Channel Power MOSFET ทำหน้าที่เป็นสวิตช์ตัดต่อวงจรเมื่อเกิดสภาวะผิดปกติ

```text
5V USB-C / IN+/IN-
        ↓
    [TC4056A] ── CC/CV Algorithm (1A Charge Current)
        │
        ├──> [B+, B-] ──> ต่อตรงเข้าแบตเตอรี่ 18650
        │
    [DW01A + 8205A] ── วงจรป้องกัน (ตัดไฟเมื่อแบตต่ำ < 2.5V หรือโหลดช็อต > 3A)
        │
        └──> [OUT+, OUT-] ──> ขั้วจ่ายไฟไปยังโหลดที่มีระบบป้องกัน
```

## 2. ตารางข้อมูลจำเพาะ (Technical Specifications)

| พารามิเตอร์ | ค่าสเปก | หมายเหตุ |
|---|---|---|
| **แรงดันไฟเข้า (Input Voltage)** | **4.5V – 5.5V DC** | ผ่านพอร์ต USB-C หรือจุดบัดกรี `IN+` / `IN-` |
| **แรงดันชาร์จเต็ม (Full Charge Cutoff)** | **4.20V ± 1%** | มาตรฐาน Li-ion 1S |
| **กระแสชาร์จสูงสุด (Max Charge Current)** | **1000 mA (1.0 A)** | กำหนดโดยตัวต้านทาน $R_{prog}$ (1.2kΩ) |
| **แรงดันตัดการคายประจุ (Under-voltage Cutoff)** | **~2.5V** | ป้องกันแบตเตอรี่ 18650 คายประจุจนพัง (โดย DW01A) |
| **กระแสตัดการลัดวงจร (Over-current Cutoff)** | **~3.0 A** | ตัดวงจรเมื่อโหลดกินกระแสเกินหรือลัดวงจร |
| **ไฟแสดงสถานะ (LED Status)** | 🔴 **สีแดง (CHRG):** กำลังชาร์จ<br>🟢 **สีเขียว (STDBY):** ชาร์จเต็มแล้ว | อยู่ที่ขอบบนของบอร์ด |

## 3. แผนผังจุดเชื่อมต่อและรูบัดกรีบนบอร์ด (Pinout & Pad Layout)

```text
               [ ไฟ LED แดง (กำลังชาร์จ) | ไฟ LED เขียว (เต็ม) ]
                              ▲                ▲
       ┌──────────────────────┴────────────────┴──────────────────────┐
       │                                                              │
(🔴) ──┼──► [ Input + ]                                  [ Output + ] ├──► (🔴 จ่ายไฟออกไปโหลด +)
       │                                                              │
[USB-C]│ [ Type-C 5V ]                                          [ B+ ] ├──► (🔴 ต่อขั้วบวกถ่าน 18650)
       │                                                              │
       │                                                        [ B- ] ├──► (⚫ ต่อขั้วลบถ่าน 18650)
       │                                                              │
(⚫) ──┼──► [ Input - ]                                  [ Output - ] ├──► (⚫ จ่ายไฟออกไปโหลด -)
       │                                                              │
       └──────────────────────────────────────────────────────────────┘
```

### รายละเอียดจุดเชื่อมต่อทั้ง 3 กลุ่ม (6 รูบัดกรี + 1 พอร์ต USB-C):

| จุดเชื่อมต่อ (Pad) | ทิศทาง | ประเภท | คำอธิบายการต่อใช้งาน |
|---|:---:|:---:|---|
| **USB-C Port** | Input | พอร์ตเสียบ | ช่องเสียบสายชาร์จ 5V จาก Adapter มือถือ หรือ Power Supply ภายนอก |
| **`Input +` (`IN+`)** | Input | รูบัดกรีมุมบนซ้าย | จุดรับ **ไฟบวก 5V DC จากสายไฟเปลือย/จัมเปอร์** (เช่น ต่อรับไฟ 5V จากขา `OUT+` ของ MT3608 Boost) |
| **`Input -` (`IN-`)** | Input | รูบัดกรีมุมล่างซ้าย | จุดรับ **กราวด์ (GND) ไฟเข้า** (ต่อรับกราวด์จากขา `OUT-` ของ MT3608 Boost) |
| **`B+`** | I/O | รูบัดกรีฝั่งขวาบน | ต่อเข้า **ขั้วบวก (+)** ของแบตเตอรี่ 18650 (สายสีแดงจาก 1S2P Holder) เพื่อชาร์จไฟเข้าเซลล์ |
| **`B-`** | I/O | รูบัดกรีฝั่งขวาล่าง | ต่อเข้า **ขั้วลบ (-)** ของแบตเตอรี่ 18650 (สายสีดำจาก 1S2P Holder) เพื่อชาร์จไฟเข้าเซลล์ |
| **`Output +` (`OUT+`)** | Output | รูบัดกรีมุมบนขวา | ไฟบวกจ่ายออกไปหาโหลดภายนอก (3.0V – 4.2V ตามระดับแบตเตอรี่) |
| **`Output -` (`OUT-`)** | Output | รูบัดกรีมุมล่างขวา | กราวด์จ่ายออกไปหาโหลด **ผ่านชิปป้องกัน DW01A + 8205A MOSFET** (ตัดไฟทันทีเมื่อแบตต่ำกว่า 2.5V หรือโหลดลัดวงจร) |

## 4. บทบาทและความอเนกประสงค์ในโปรเจกต์ StepCharge

1. **รองรับการต่อไฟแบบสายไฟเปลือย (Bare-Wire Input):**
   * บอร์ด PowerBank มีแค่ช่องเสียบ Type-C ตัวเมีย แต่ TP4056 มีรู **`Input +` / `Input -`** ทำให้สามารถนำสายไฟจากวงจร Boost Converter (MT3608) มาบัดกรีเข้าได้โดยตรง โดยไม่ต้องตัดต่อสาย USB
2. **ระบบชาร์จมาตรฐาน Li-ion ปลอดภัย (CC/CV Algorithm):**
   * ชาร์จด้วยกระแสคงที่ (Constant Current) จนถึง 4.20V แล้วปรับเป็นแรงดันคงที่ (Constant Voltage) ก่อนตัดไฟอัตโนมัติเมื่อแบตเตอรี่เต็ม
3. **ระบบป้องกันแบตเตอรี่สมบูรณ์แบบ (Dual Protection):**
   * มีชิป DW01A คอยตรวจสอบแรงดัน หากดึงโหลดจนแบตเตอรี่ต่ำกว่า 2.5V วงจรจะตัดไฟที่ขา `OUT-` ทันทีเพื่อรักษาอายุการใช้งานของถ่าน 18650

## 5. ข้อควรระวังในการใช้งาน (Safety Guidelines)

> [!IMPORTANT]
> - **ห้ามต่อ Piezo เข้า TP4056 โดยตรง:** TP4056 ต้องการไฟ DC ต่อเนื่อง 4.5V–5.5V ต้องผ่านวงจร Rectifier + Storage + Boost Converter ก่อนเสมอ
> - **ห้ามจ่ายไฟชาร์จเข้าพร้อมกัน 2 ทาง:** ในเวลาเดียวกัน ให้เลือกจ่ายไฟเข้าทางพอร์ต USB-C **หรือ** รู `Input + / Input -` เพียงอย่างใดอย่างหนึ่งเท่านั้น
> - **การต่อร่วมกับ PowerBank Module:** สาย `B+ / B-` ของ TP4056 สามารถต่อขนานเข้ากับสายรางถ่าน 18650 ร่วมกับบอร์ด PowerBank ได้อย่างปลอดภัย (TP4056 รับไฟเข้าเพื่อชาร์จ / PowerBank ดึงไฟออกเพื่อบูสต์เป็น 5V)
