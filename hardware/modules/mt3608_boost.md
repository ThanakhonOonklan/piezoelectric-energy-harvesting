# MT3608 DC-DC Step-Up (Boost) Converter Module

เอกสารสเปก Pinout การตั้งค่าแรงดัน และการต่อใช้งานจริงของโมดูลบูสต์แรงดัน **MT3608 2A Boost Converter** ในระบบ StepCharge

---

## 1. ภาพรวมและหน้าที่ในระบบ (Overview & Function)

โมดูล **MT3608** ทำหน้าที่เป็น **สะพานเชื่อมระดับแรงดัน (Voltage Bridge)** ในระบบเก็บเกี่ยวพลังงาน โดยรับแรงดันเอาต์พุต 3.3V จากบอร์ด **LTC3588 Harvester** แล้วทำการบูสต์เพิ่มแรงดันขึ้นเป็น **5.0V – 5.2V DC** เพื่อป้อนเข้าสู่จุดบัดกรี `Input + / Input -` ของโมดูลชาร์จแบตเตอรี่ **TP4056** อย่างสมบูรณ์

```text
[ LTC3588 VCC ] (3.3V Pulse/Burst)
        ↓
 [ MT3608 IN+ / IN- ]
        ↓
    (Boost Inductor 22µH + MT3608 IC @ 1.2MHz)
        ↓
 [ MT3608 OUT+ / OUT- ] (ปรับตั้งค่าไว้ที่ 5.20V DC)
        ↓
 [ TP4056 Input + / Input - ] ──► ชาร์จเข้าแบตเตอรี่ 18650 (~4.0V)
```

## 2. ข้อมูลจำเพาะทางเทคนิค (Technical Specifications)

| พารามิเตอร์ | ค่าสเปก | หมายเหตุสำหรับการใช้งานจริง |
|---|---|---|
| **ชิปควบคุม (IC)** | **Aerofemi MT3608** | High-efficiency 1.2MHz Step-up Converter |
| **แรงดันไฟเข้า (Input Voltage)** | **2.0V – 24.0V DC** | รองรับไฟ 3.3V จาก LTC3588 ได้อย่างดีเยี่ยม |
| **แรงดันไฟออก (Output Voltage)** | **5.0V – 28.0V DC** | ปรับค่าด้วย Trimpot (ในระบบตั้งไว้ที่ **5.20V**) |
| **กระแสจ่ายออกสูงสุด (Max Output Current)** | **2.0 A** | เกินพอสำหรับความต้องการของระบบ Piezo |
| **ประสิทธิภาพการแปลงผัน (Efficiency)** | **สูงสุด 93%** | สูญเสียพลังงานในรูปความร้อนต่ำ |
| **ความถี่สวิตชิ่ง (Switching Frequency)** | **1.2 MHz** | ทำให้ใช้อินดักเตอร์และตัวเก็บประจุขนาดเล็กได้ |

```text
       │                                                  │

```

## 4. ขั้นตอนการปรับตั้งค่าและผลการทดสอบจริง (Calibration & Verified Results)

1. **การปรับตั้งค่าเริ่มต้น (2026-08-27):**
   * ป้อนไฟ 3.3V เข้าช่อง `IN+ / IN-`
   * วัดแรงดันเริ่มต้นจากโรงงานที่ช่อง `OUT+ / OUT-`: วัดได้ **18.0V**
   * ทำการหมุนปรับสกรูตัวต้านทานปรับค่าได้ (Trimpot) ทวนเข็มนาฬิกา จนกระทั่งแรงดันลดลงมาอยู่ที่ **`5.20 V`**
2. **ผลการทำงานร่วมกับระบบจริง:**
   * เมื่อ LTC3588 สะสมประจุถึง ~4.6V - 5.0V (80% - 100%) และปล่อยพลังงานออกมา MT3608 สามารถบูสต์ไฟขึ้น 5.2V และส่งผ่านให้ TP4056 ชาร์จแบตเตอรี่ 18650 ที่แรงดันประมาณ **~4.0V** ได้จริงสมบูรณ์แบบ
